# SortVision

SortVision is a sorting algorithm learning project focused on understanding how different sorting algorithms work internally.

The project is currently a **CLI (Command Line Interface) application written in C++**. It allows users to provide an input array, choose a sorting algorithm, and observe the sorted output. The primary goal of the project is educational—to explore, implement, and compare multiple sorting techniques from scratch.

This project is being developed in stages. The current version focuses on implementing and testing sorting algorithms in a console environment. Future versions may expand beyond the command line and provide a more interactive way to understand the sorting process.

## Current Features

* Menu-driven CLI application
* Multiple sorting algorithms implemented from scratch
* Single input array can be used to test different algorithms
* Clean modular code structure using separate source files
* Educational focus on algorithm behavior and comparison

## Implemented Algorithms

## Purpose

The objective of SortVision is not just to sort data, but to build a deeper understanding of how different sorting algorithms operate, how their approaches differ, and what trade-offs they make in terms of efficiency and behavior.

As the project evolves, it will continue to focus on making sorting algorithms easier to learn, compare, and explore.
